# 📋 TaskFlow - Application de gestion de tâches collaboratives

## 🎯 Contexte du Projet
Mini-projet réalisé dans le cadre du module **Conception Logicielle**. 
TaskFlow est une application permettant à plusieurs utilisateurs de créer, organiser et suivre l'avancement de tâches au sein d'un projet.

## 🏗️ Architecture et Conception
Le projet respecte les principes **SOLID** et **KISS**. Nous avons intégré les Design Patterns suivants :
- **Singleton :** Pour garantir une instance unique de la connexion à la base de données.
- **Factory :** Pour gérer la création et l'instanciation des objets `Tache`.
- **Observer :** Pour le système de notifications (alerter un membre quand une tâche lui est assignée).

## 📂 Structure du projet
- `docs/diagrammes/` : Contient les diagrammes UML (Cas d'utilisation, Classes, Séquences, Activité).
- `src/` : Code source en Python (Modèles et Patterns).
- `swagger.yaml` : Documentation de l'API REST.
